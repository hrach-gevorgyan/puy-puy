# audio.md — every spoken clip

**59 speech clips**, all of them Պույ-պույ, plus four non-verbal clips borrowed from
hashvir. Every one lives in `app/src/main/res/raw` and is committed: they are build *inputs*,
not build outputs, so the app builds and runs with no network.

This file exists so the whole set can be re-recorded — in a real voice, or another language —
without guessing at what each clip says. `tools/words.csv` is the machine-readable version of
the same list and is what the generator actually reads.
